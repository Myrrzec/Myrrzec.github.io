01Interactive web walkthrough

Explore UTP

HTML · CSS · JavaScriptSVGVideo-readyMobile

A point-and-click walkthrough of my own university campus, Universiti Teknologi PETRONAS. You click a place on an illustrated map, read about it, then step inside a full-screen virtual view and explore it by tapping points of interest.

What I built

  • An illustrated campus map with numbered places; clicking one zooms the map smoothly and opens a description panel, with Previous / Next for a guided tour
  • An "Experience it virtually" mode: a full-screen view with clickable points that reveal details, and a day / night switch that changes the whole scene
  • Every place plays a video clip when one is added; until then an illustrated scene stands in, so the experience never shows a broken player
  • Shareable links to any place or straight into its virtual view, so a main website can link to a specific stop

Problems I solved

  • On phones the wide scene is cropped, so clickable points drifted off their objects; the scene, video and points now share one frame, and you drag sideways to look around
  • The location panel covered the place it described, so the map zoom shifts each place clear of the panel on desktop and above the bottom sheet on mobile

A student concept, not an official UTP website. Plain HTML, CSS and JavaScript with no build step.

02Full-stack app

KBJU Tracker

Python · FastAPIPostgreSQLReact · TypeScriptTailwindClaude API

A calorie and macro tracker. You photograph a meal and AI estimates calories, protein, fat and carbs, which you can correct before saving to a daily diary.

What I built

  • Sign-up and login with JWT tokens, user profile and daily targets from the Mifflin-St Jeor formula
  • Food-photo recognition with Claude Vision, returning structured JSON through tool use
  • Diary with meals grouped by photo or time (Lunch 1, Lunch 2), inline editing, recent dishes, AI advice
  • Responsive dark UI built from a written design brief; deployed as three separate services

Problems I solved

  • The AI refused unclear photos, so I rewrote the prompt to give a best-effort estimate with a confidence level and a note
  • Entries near midnight landed on the wrong day, so day boundaries now use the user's timezone
  • Raw API errors leaked to users, so they are mapped to short readable messages

Free hosting: the first request after a pause can take 30–50 seconds while the server wakes up.
